# Space War

Двухигроковая аркада на Pygame: два игрока за одной клавиатурой управляют
космическими кораблями-бубликами с инерцией и стреляют ракетами.

## Запуск

```bash
uv sync
uv run python main.py
```

Игра запускается в полноэкранном режиме; игровое поле занимает весь экран.
Выход — клавиша `Escape`.

## Управление

Каждый игрок управляет своим кораблём и стреляет своей клавишей Shift.

| Действие                                  | Игрок 1 | Игрок 2   |
| ----------------------------------------- | ------- | --------- |
| Поворот против часовой стрелки            | `A`     | `←`       |
| Поворот по часовой стрелке                | `D`     | `→`       |
| Двигатель (тяга), пока удерживается кнопка | `W`     | `↑`       |
| Ракета                                     | `Shift` | `Shift`   |

Двигатель разгоняет корабль вдоль его носа. Если нос смотрит по вектору
движения — корабль ускоряется, если против — тормозит, если перпендикулярно —
поворачивает траекторию. Корабль движется по инерции без сопротивления.

Движение моделируется по специальной теории относительности: с ростом
скорости растёт релятивистская масса (`m = γ·m₀`), поэтому конечная тяга
разгоняет всё слабее, и корабли не могут достичь «скорости света» — она лишь
асимптотический предел. Тот же предел ограничивает ракеты и результат упругих
столкновений кораблей.

## Игровые правила

- Мир без границ: вылет за край ведёт к появлению с противоположной стороны.
- Ракет у каждого три; запас медленно пополняется со временем.
- Ракета живёт фиксированное время полёта и по его истечении взрывается сама;
  дальность при этом зависит от её скорости.
- Попадание ракеты в чужой корабль уничтожает его: победитель получает очко,
  раунд начинается заново.
- Одна ракета может подбить другую ракету.
- Столкновение кораблей — упругое, как у биллиардных шаров равной массы: ущерб
  не наносится.
- Эффекты: корабли нарисованы процедурно с подсветкой, ореолом и пламенем
  двигателя при тяге; ракеты оставляют след. При попадании ракеты корабль
  взрывается, обломки разлетаются и гаснут, а новый раунд начинается после
  короткой паузы — чтобы взрыв было видно. Во время этой паузы только
  откладывается респавн: уцелевший корабль продолжает лететь по инерции, а
  выпущенные ракеты продолжают движение. Обломки наследуют скорость
  погибшего корабля, поэтому облако дрейфует в сторону его движения. Обломки
  чисто визуальные и не влияют на столкновения, урон или счёт.

## Настройка

Все игровые константы и раскладки клавиш вынесены в
`space_war/config.py` (`GameConfig`): радиус и масса корабля, скорость
поворота, ускорение тяги, скорость/радиус/время жизни ракеты, стартовый и
максимальный запас ракет, интервал пополнения, стартовые позиции и курс, цвета
и привязки клавиш. Размеры поля берутся из разрешения экрана в полноэкранном
режиме. Там же настраиваются эффекты и пауза разрушения: `destruction_pause`
(по умолчанию 1.0 c), `debris_count`, `debris_speed`, `debris_lifetime`,
`flame_length`, `trail_length`, `glow_radius`. Скорость света задаётся
параметром `speed_of_light`; масса покоя корабля — `ship_mass`; время жизни
ракеты — `missile_lifetime` (по умолчанию 1.5 c).
