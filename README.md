# Space War

Двухигроковая аркада на Pygame: два игрока за одной клавиатурой управляют
космическими кораблями-бубликами с инерцией и стреляют ракетами.

## Запуск

```bash
uv sync
uv run python main.py
```

Игра запускается в полноэкранном режиме; игровое поле занимает весь экран.
Выход — клавиша `Escape`.

## Управление

Каждый игрок управляет своим кораблём и стреляет своей клавишей Shift.

| Действие                                  | Игрок 1 | Игрок 2   |
| ----------------------------------------- | ------- | --------- |
| Поворот против часовой стрелки            | `A`     | `←`       |
| Поворот по часовой стрелке                | `D`     | `→`       |
| Двигатель (тяга), пока удерживается кнопка | `W`     | `↑`       |
| Ракета                                     | `Shift` | `Shift`   |

Двигатель разгоняет корабль вдоль его носа. Если нос смотрит по вектору
движения — корабль ускоряется, если против — тормозит, если перпендикулярно —
поворачивает траекторию. Корабль движется по инерции без сопротивления.

## Игровые правила

- Мир без границ: вылет за край ведёт к появлению с противоположной стороны.
- Ракет у каждого три; запас медленно пополняется со временем.
- Ракета пролетает ограниченную дистанцию и сама взрывается по времени.
- Попадание ракеты в чужой корабль уничтожает его: победитель получает очко,
  раунд начинается заново.
- Одна ракета может подбить другую ракету.
- Столкновение кораблей — упругое, как у биллиардных шаров равной массы: ущерб
  не наносится.

## Настройка

Все игровые константы и раскладки клавиш вынесены в
`space_war/config.py` (`GameConfig`): радиус и масса корабля, скорость
поворота, ускорение тяги, скорость/радиус/дальность ракеты, стартовый и
максимальный запас ракет, интервал пополнения, стартовые позиции и курс, цвета
и привязки клавиш. Размеры поля берутся из разрешения экрана в полноэкранном
режиме.

## Тесты

Симуляция не зависит от окна и покрыта модульными тестами:

